= Типы данных в языке C

== Типизация в языке C

Прежде чем изучать конкретные типы, важно понять, как язык C работает с типами в целом.

Язык C обладает **статической типизацией**: тип каждой переменной известен на этапе компиляции, и компилятор проверяет корректность операций с типами до запуска программы. Если вы попытаетесь выполнить недопустимую операцию, компилятор выдаст ошибку.

[source,c]
----
int x = 10;
char *str = x;  // Ошибка компиляции: нельзя присвоить int указателю на char
----

Однако типизация в C считается **слабой** (или нестрогой). Это означает, что язык допускает множество неявных преобразований между типами, которые в других языках вызвали бы ошибку. Компилятор C часто сам «догадывается», как преобразовать один тип в другой, даже если это может привести к потере данных или неожиданному поведению.

Примеры слабой типизации в C:

[source,c]
----
int x = 10;
double y = x;           // Неявное преобразование int в double — разрешено

int a = 5;
long b = a;             // Неявное расширение типа — разрешено

int *ptr = NULL;
if (ptr) {              // Указатель неявно преобразуется в логическое значение
    // ...
}

void *generic_ptr;
int *int_ptr = generic_ptr;  // В C указатель void* неявно преобразуется
                             // в любой другой тип указателя (в C++ это запрещено)
----

TIP: Слабая типизация даёт гибкость, но требует от программиста внимательности. Компилятор C не будет защищать вас от всех возможных ошибок типов — он предполагает, что вы знаете, что делаете. Именно поэтому важно включать предупреждения компилятора (флаги `-Wall -Wextra` в GCC/Clang), чтобы ловить подозрительные преобразования.

== Что такое тип данных

Любая переменная в программе — это именованная область памяти. Но процессор не знает, что такое «число», «символ» или «адрес». Для него всё — это просто последовательности нулей и единиц. Чтобы компьютер мог правильно работать с данными, ему нужно сообщить две вещи:

. К какой *смысловой категории* (домену) относятся данные: целое число, дробное число, символ, адрес в памяти.
. Какие *операции* над этими данными имеют смысл: сложение, деление, побитовый сдвиг, разыменование.

Именно эти две задачи и решает **тип данных**. Тип — это контракт между программистом и компилятором: «Я обещаю, что в этой области памяти лежат данные определённого вида, и прошу выполнять над ними только допустимые операции».

NOTE: Тип не определяет физический размер переменной в байтах и не фиксирует способ кодирования значений. Эти детали зависят от конкретной платформы. Стандарт языка C гарантирует только домен данных и набор допустимых операций — именно это делает программы на C переносимыми между разными архитектурами.

== Базовые типы

Язык C предоставляет несколько базовых типов, каждый из которых относится к своему домену.

=== Целочисленные типы

К домену целых чисел относятся:

[cols="1,3",options="header"]
|===
| Тип | Описание

| `char`
| Символьный тип. Исторически занимает один байт (ровно один байт — единственная гарантия стандарта). Может использоваться и как маленький целочисленный тип.

| `short`
| Короткое целое.

| `int`
| Целое число «естественного» для процессора размера. Основной рабочий тип для целых чисел.

| `long`
| Длинное целое.

| `long long`
| Очень длинное целое (гарантированно не меньше 64 бит).
|===

Между размерами этих типов действует правило:

[source]
----
sizeof(char) <= sizeof(short) <= sizeof(int) <= sizeof(long) <= sizeof(long long)
----

Над целыми числами допустимы:

* арифметические операции: `+`, `-`, `*`, `/`, `%`;
* операции сравнения: `==`, `!=`, `<`, `>`, `<=`, `>=`;
* побитовые операции: `&`, `|`, `^`, `~`, `<<`, `>>`;
* инкремент и декремент: `++`, `--`.

=== Типы с плавающей точкой

К домену приближённых вещественных чисел относятся:

[cols="1,3",options="header"]
|===
| Тип | Описание

| `float`
| Число одинарной точности.

| `double`
| Число двойной точности. Как правило, точнее и больше по диапазону, чем `float`.

| `long double`
| Число расширенной точности.
|===

Над числами с плавающей точкой допустимы арифметические операции (`+`, `-`, `*`, `/`) и операции сравнения. Зато *недопустимы* побитовые операции и операция взятия остатка `%` — она определена только для целых.

=== Тип void

Тип `void` означает «отсутствие значения». Он используется:

* для функций, которые ничего не возвращают: `void print_hello(void);`
* как базовый тип для указателей: `void *` — указатель на данные неизвестного типа.

== Модификаторы типов

Целочисленные типы (кроме `void`) можно уточнять с помощью модификаторов.

=== Знаковость: `signed` и `unsigned`

По умолчанию целочисленные типы являются знаковыми (`signed`), то есть могут представлять как положительные, так и отрицательные значения. Модификатор `unsigned` означает, что переменная хранит только неотрицательные значения, но зато её диапазон в положительную сторону примерно вдвое шире.

[source,c]
----
int x = -10;          // знаковое целое
unsigned int y = 10;  // только неотрицательные
----

TIP: Тип `char` по умолчанию может быть как знаковым, так и беззнаковым — это зависит от платформы. Если вам важна знаковость, всегда явно пишите `signed char` или `unsigned char`.

=== Размеры: `short` и `long`

Модификаторы `short` и `long` позволяют попросить у компилятора тип меньшего или большего размера. Они применяются к целым типам и к типам с плавающей точкой:

[source,c]
----
short int a;       // короткое целое
long int b;        // длинное целое
long long int c;   // очень длинное целое
long double d;     // вещественное число расширенной точности
----

Слова `int` в таких объявлениях можно опускать: `short a;` и `long b;` — полностью корректные записи.

== Оператор sizeof

Хотя стандарт не фиксирует точные размеры типов, программа может узнать их во время компиляции с помощью оператора `sizeof`. Он возвращает размер объекта или типа в байтах (в «байтах языка C», где байт — это `sizeof(char)`).

[source,c]
----
#include <stdio.h>

int main(void) {
    printf("char:       %zu\n", sizeof(char));
    printf("int:        %zu\n", sizeof(int));
    printf("long:       %zu\n", sizeof(long));
    printf("long long:  %zu\n", sizeof(long long));
    printf("float:      %zu\n", sizeof(float));
    printf("double:     %zu\n", sizeof(double));
    printf("pointer:    %zu\n", sizeof(void*));
    return 0;
}
----

WARNING: Оператор `sizeof` вычисляется на этапе компиляции для конкретной целевой платформы. Запустив одну и ту же программу на разных машинах, вы можете получить разные значения. Это нормально и соответствует философии C.

Для переносимого кода, где важны точные размеры, в стандартной библиотеке (заголовок `<stdint.h>`, начиная с C99) предусмотрены типы с гарантированной шириной: `int32_t`, `uint64_t` и подобные.

== Приведение типов

Часто возникает необходимость преобразовать значение одного типа к другому. Компилятор делает это двумя способами.

=== Неявное приведение

Компилятор сам преобразует типы, когда это безопасно и имеет смысл. Например, при смешанных арифметических операциях меньший тип автоматически расширяется до большего:

[source,c]
----
int x = 10;
double y = 3.5;
double z = x + y;  // x неявно преобразуется к double
----

=== Явное приведение (cast)

Если программист хочет выполнить преобразование явно, используется оператор приведения типов:

[source,c]
----
double pi = 3.14159;
int n = (int)pi;   // n станет равным 3, дробная часть отбрасывается

int value = 1000;
char c = (char)value;  // сохранится только младший байт
----

CAUTION: Явное приведение — мощный, но опасный инструмент. При преобразовании `double` в `int` теряется дробная часть, при преобразовании большого целого в малое — старшие разряды. Используйте cast осознанно.

== Пользовательские имена типов: typedef

Ключевое слово `typedef` позволяет ввести собственное имя для уже существующего типа. Это не создаёт новый тип, а лишь даёт ему псевдоним:

[source,c]
----
typedef unsigned long size_type;
typedef int boolean;

size_type length = 100;
boolean flag = 1;
----

TIP: `typedef` особенно полезен для:

* повышения читаемости кода, когда имя типа несёт смысловую нагрузку (`size_type` вместо `unsigned long`);
* упрощения переноса кода между платформами — достаточно изменить одно определение `typedef`, а не переписывать весь код;
* работы со сложными типами, например, с указателями на функции.

== Итоги

* Язык C обладает **статической слабой типизацией**: типы проверяются на этапе компиляции, но допускается множество неявных преобразований между типами.
* Тип данных определяет *домен* (смысловую категорию) переменной и набор *допустимых операций* над ней.
* Физический размер и способ кодирования значений зависят от платформы — это детали реализации, а не часть определения типа.
* Базовые типы C делятся на целочисленные (`char`, `short`, `int`, `long`, `long long`), вещественные (`float`, `double`, `long double`) и специальный тип `void`.
* Целочисленные типы можно уточнять модификаторами знаковости (`signed`, `unsigned`) и размера (`short`, `long`, `long long`).
* Оператор `sizeof` позволяет узнать размер типа на конкретной платформе.
* Приведение типов бывает неявным (автоматическим) и явным (через оператор cast).
* Ключевое слово `typedef` создаёт псевдонимы для типов, улучшая читаемость и переносимость кода.

Понимание типов — это основа работы на языке C. Типы помогают компилятору генерировать корректный машинный код, а программисту — выражать свои намерения ясно и избегать целого класса ошибок.
